# Start here

This pack converts Abdulla's Dubai-inspired life/real-estate game concept into an implementation brief for Claude Code. **Salary to Skyline** is a working title, not a cleared brand. The package contains specifications and illustrative data, not an executable app or commissioned art.

## What to give Claude

Unzip this folder into an approved workspace, or place the Markdown documents and JSON file in the intended repository. Ask Claude to inspect the repository before editing. The combined single-file version supplied alongside the ZIP contains the same principal document sections for convenient upload; do not maintain conflicting versions.

Paste this instruction:

> Read START_HERE.md and CLAUDE.md first, then the master brief, economy spec, and build/acceptance plan. Build the game described, not a generic idle property app or a collection of screens. Preserve the original Gulf-city identity, player-controlled monthly time, jobs/study/life costs, ready/off-plan/fractional property, rentals, fictional crypto, businesses, lifestyle progression, and modern UI over original isometric pixel art.
>
> Inspect the repository and local toolchain. Then implement M0 only: pin a compatible Godot/GDScript setup, create the minimal portrait project, implement tested money and monthly salary/expense flow with reliable save/load, and investigate the real iOS/Android export and purchase path. Use the supplied arithmetic/data fixtures and create the project-level headless test runner.
>
> Do not start by generating the whole city, adding a backend, selling virtual cash, or producing a “finished” mockup. Report what runs, exact tests executed, screenshots or build evidence, and anything requiring my credentials or approval. Do not publish, spend money, create external services, or change the commercial model. After M0, propose the next smallest playable milestone. We must prove the first-property experience at M2 before expanding the feature set.

## Files

| File | Purpose |
|---|---|
| `CLAUDE.md` | Persistent repository instructions, constraints, scope, and permissions. |
| `MASTER_BUILD_BRIEF.md` | Player experience, full game systems, art/UI, architecture, commercial model, and scope. |
| `ECONOMY_SPEC.md` | Financial definitions, monthly sequence, formulas, fixtures, and anti-exploit rules. |
| `BUILD_PLAN_AND_ACCEPTANCE.md` | Milestones, first tickets, 60 acceptance cases, and evidence requirements. |
| `PLAYTEST_AND_LAUNCH.md` | Research, metrics, economics, and launch decisions. |
| `starter_balance.json` | A small machine-readable set of fictional starter settings and arithmetic fixtures. Not a full content database. |
| `SOURCES_AND_ASSUMPTIONS.md` | Primary sources, uploaded-course references, and the distinction between evidence and design assumptions. |
| `PACK_VERIFICATION.md` | Checks performed on the document/data package; not game QA. |
| `MANIFEST.sha256` | Checksums of the package's other files. |

The game has not been built or playtested by creating this pack. The suggested pacing, retention, price, and economy require testing. Start small enough to learn, while keeping the full vision visible.

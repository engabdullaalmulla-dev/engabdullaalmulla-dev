Café Rush · art kit v1

Every asset is code

No illustrator, no stock packs, no raster files. Each asset below is hand-written SVG built from circles, rounded rectangles and short curves, on one 64×64 grid with one light source. That is what makes twenty assets look like they came from the same hand — the rules are literally enforced in the source.

The rules

Six constraints. Every asset obeys all six, which is the whole trick.
64 × 64 gridOne viewBox for everything. Objects sit within a 6-unit margin so nothing clips when scaled down.
Light from top-leftEvery form gets one lighter face and one darker face, always on the same sides. Never a gradient.
No outlinesShapes read by fill contrast alone, so assets sit on the dark counter and on white UI without a second version.
Contact shadowOne ellipse at 14% black beneath every object. It is what stops icons floating.
Silhouette firstEach item is identifiable in solid black at 20px. Detail is added only after the outline reads.
Radius 4–5Corners share one radius language. Glass is the only exception and it is always straight-sided.

What this costs to change: nothing but a text edit. Recolouring the whole game for a night shift is fourteen hex values. Adding a new drink is one symbol. A complete restyle is a find-and-replace, not a re-commission — which is the real reason to author art as code when there is no illustrator.
